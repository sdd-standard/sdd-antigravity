# SDD Design

O Design diz COMO o sistema vai atingir O QUE foi definido nos requisitos (GEARS).

## Passos:
1. Leia os requisitos GEARS envolvidos.
2. Formule as decisões arquiteturais, de banco de dados, fluxos ou componentes visuais necessários.
3. Se for Greenfield, escreva no `05-design.md`.
4. Se for alteração, atualize a Delta Spec ou o Design central com as novas decisões, usando o padrão `DES-XXX`.
5. Identifique potenciais dependências e justifique (rationale) por que você tomou cada decisão.
