# SDD Tasks

Deriva tarefas de execução (coding tasks) a partir do design estabelecido.

## Passos:
1. Analise o `05-design.md` ou a delta spec ativa.
2. Identifique os passos atômicos necessários para implementar o design.
3. Crie tarefas no `07-tasks.md` seguindo o formato de ledger com Status (Pending, In Progress, Done, Blocked).
4. Indique as referências (Related: FR-XXX, DES-YYY) e critérios de aceite rápidos (`Done When`).
